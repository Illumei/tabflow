# TabFlow — Tab Manager

TabFlow — это легкий и быстрый менеджер вкладок для браузеров на базе Chromium (Chrome, Opera, Edge). 

## 🚀 Возможности
- 🔍 **Поиск:** Мгновенный поиск по всем открытым вкладкам.
- 💾 **Рабочие пространства:** Сохраняйте наборы вкладок (например, "Работа") и открывайте их в один клик.
- ⭐ **Избранное:** Быстрое сохранение важных страниц через контекстное меню.
- 🌙 **Автоусыпление (Pro):** Неактивные вкладки засыпают, экономя оперативную память.
- 🛡️ **Crash Recovery (Pro):** Восстановление сессии после вылета браузера.
- 🗂 **Группировка:** Автоматическая группировка вкладок по домену.
- 🧹 **Очистка:** Мгновенное закрытие дубликатов страниц.
- 🎨 **Темы:** Светлая и тёмная темы.

## 🔒 Конфиденциальность
Расширение не собирает и не передает ваши данные. Все настройки и сессии хранятся локально или синхронизируются через ваш браузер.
